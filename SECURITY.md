# Security Policy

Modern Telengard is pre-alpha software. The supported security baseline is the
current `main` branch and the latest published project state.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use
[GitHub private vulnerability reporting](https://github.com/JackSmack1971/telengard-reloaded/security/advisories/new).
If private reporting is unavailable, contact `@JackSmack1971` through GitHub
with **Security** in the subject and request a private conversation.

Include the affected component, reproducible steps, impact, and any proposed
mitigation. Do not include credentials, private data, or a proof of concept
that exposes real secrets.

## Response

The maintainer will acknowledge reports when able, reproduce and assess the
issue, and coordinate disclosure and remediation as appropriate. Response and
fix timelines are not guaranteed for this pre-alpha project.

## Scope

Reports may cover the headless simulation, save handling, content loading,
Terminal tooling, repository automation, and the Godot presentation boundary.
