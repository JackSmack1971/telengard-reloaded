# TEL-112 — Author first-slice encounter ecology tables

## Purpose / user-visible outcome

The versioned content pack exposes deterministic encounter ecology for the
Upper Ruins floors 1–5. The existing simulation trigger can consume the table
through an adapter without moving encounter resolution into content or the
renderer.

## Scope and non-goals

- Add the encounter-table schema, loader catalog, reference/range validation,
  authored Upper Ruins table, and focused tests.
- Add weighted selection to the existing encounter trigger option boundary.
- Do not add a new trigger algorithm, combat behavior, pacing model, or
  renderer behavior. Balance and trigger chance remain configuration.

## Invariants and save/version impact

Content remains immutable configuration; unknown monster references and invalid
ranges/weights are rejected before catalog publication. Selection uses the
existing scoped deterministic RNG and emits the existing encounter event.
Save DTOs, migrations, save version, and content-version fields are unchanged.

## Validation

- Focused encounter/content tests — passed (23 tests).
- `./eng/dotnet.ps1 format Telengard.sln --verify-no-changes` — passed.
- `./eng/verify.ps1 -Mode Full` — passed: 418 Release tests, 0 warnings,
  0 errors, deterministic harness checks passed.

## Results / remaining work

The first-slice table and trigger bridge are implemented without a save-schema
or content-version change. Encounter tuning, loot ecology, and later content
remain owned by their separate TEL tickets.
