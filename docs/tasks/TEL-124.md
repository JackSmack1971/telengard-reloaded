# TEL-124 — Build first-slice dungeon and content graybox presentation

## Design Intent

Render the real floors 1-5 content in Godot with production-shaped placeholder
assets so camera, scale, visibility, biome, monster, and feature presentation
can be validated before final art.

## Specification References

§9–§11; §16; §19–§21; §38–§39; §47–§48.

## Dependencies

TEL-110, TEL-111, TEL-112, TEL-116, TEL-121, TEL-122, TEL-123.

## Required Blueprint Context

- `docs/presentation/GODOT_CLIENT_BLUEPRINT.md`
- `docs/presentation/ART_DIRECTION_BLUEPRINT.md`
- `docs/presentation/ASSET_PIPELINE_BLUEPRINT.md`
- `docs/gates/GODOT-PLAYABLE-SLICE.md`

## Requirements

- Render the authored Upper Ruins/floors 1-5 environment from renderer-safe
  observable geometry/theme data.
- Distinguish unknown, observed, visited, and current/visible map states.
- Present player position/movement clearly.
- Give each first-slice monster a stable distinct placeholder identity.
- Give fountain, altar, pit, and teleporter stable distinct placeholder
  identities.
- Use the TEL-123 asset registry/fallback path rather than scene-local mapping
  conditionals.
- Keep all gameplay authority in the simulation.

## Non-Goals

- No final tiles/sprites/animation/VFX/audio.
- No deeper-band environment production.
- No complete HUD/inventory/spell/journal flow.

## Invariants

Unknown geography remains hidden. Presentation identity does not expose hidden
monster/feature facts. Godot visuals follow committed state/events.

## Save Impact

None expected.

## Tests / Observation

- Projection/registry tests for all first-slice identities used here.
- Fixed-seed Godot walk through representative Upper Ruins geometry.
- Visual/manual checks for fog states, player readability, monsters, and four
  features.
- Canonical full verification for code changes.

## Acceptance Criteria

A player can walk a fixed-seed real first-slice dungeon in Godot and visually
understand explored geometry, player location, observed monsters, and the four
features using placeholder assets through the production presentation path.
