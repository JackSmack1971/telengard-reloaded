# TEL-121 — Implement Godot input-to-command and simulation-clock bridge

## Design Intent

Connect keyboard/controller intent and Godot frame timing to the existing
renderer-independent command/time boundaries without making rendering FPS or UI
callbacks authoritative.

## Specification References

§12; §36–§37; §42; §44; §47–§48.

## Dependencies

TEL-120.

## Required Blueprint Context

- `docs/presentation/GODOT_CLIENT_BLUEPRINT.md`
- `docs/presentation/UX_INTERACTION_BLUEPRINT.md`
- `docs/exec-plans/active/GODOT-PLAYABLE-VERTICAL-SLICE.md`

## Requirements

- Translate required movement and foundational client intents into existing
  simulation commands.
- Establish keyboard/controller input-context handling without embedding
  gameplay legality in Godot.
- Drive normal/slowed/paused simulation behavior through the existing
  renderer-independent time/application boundary.
- Keep authoritative outcomes independent of render FPS.
- Surface rejected commands as presentation feedback without local corrective
  mutation.

## Non-Goals

- No complete combat/inventory/spell UI.
- No final control-remapping/settings UI unless strictly required by the bridge.
- No gameplay formula changes.

## Invariants

Every state-changing command is simulation-validated before mutation. Rendering
FPS does not alter simulation outcomes. UI/input code does not resolve gameplay.

## Save Impact

None expected; input bindings and transient presentation state are not
GameState save data unless separately specified.

## Tests / Observation

- Focused command mapping tests for valid/invalid contexts.
- Deterministic comparison across differing render/update cadence where
  practical.
- Pause/slowed/normal behavior checks.
- Manual Godot keyboard/controller observation when required by acceptance.
- Canonical full verification for code changes.

## Acceptance Criteria

A hosted Godot session can receive keyboard/controller intent, submit valid
simulation commands, refresh presentation from committed results, and drive the
configured simulation time mode without renderer-owned gameplay mutation or
FPS-dependent authoritative behavior.
