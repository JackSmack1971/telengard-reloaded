# TEL-128 — Verify Art Production Ready gate

## Design Intent

Convert the completed placeholder/graybox playable Godot slice into an explicit,
auditable handoff point for systematic final art, animation, VFX, UI-art, icon,
and production-audio work.

## Dependencies

TEL-110–TEL-116, TEL-123, TEL-127.

## Required Blueprint Context

- `docs/presentation/GODOT_CLIENT_BLUEPRINT.md`
- `docs/presentation/UX_INTERACTION_BLUEPRINT.md`
- `docs/presentation/ART_DIRECTION_BLUEPRINT.md`
- `docs/presentation/ASSET_PIPELINE_BLUEPRINT.md`
- `docs/gates/ART-PRODUCTION-READY.md`
- `docs/exec-plans/active/GODOT-PLAYABLE-VERTICAL-SLICE.md`

## Requirements

- Execute every acceptance item in `docs/gates/ART-PRODUCTION-READY.md`.
- Confirm stable first-slice content/presentation IDs and a reviewable asset
  inventory/matrix.
- Confirm every required production category has a working placeholder through
  the same presentation registry path intended for final resources.
- Record the chosen first-slice art-direction constraints required by the gate;
  do not invent unresolved visual-direction policy when human/product input is
  still required.
- Record asset import/naming/state conventions and binary/Git LFS policy needed
  before large production batches.
- Validate required/duplicate/missing presentation resource mappings to the
  level required by the gate.
- Author production-art TEL batches only after the gate passes, deriving their
  scope from the validated first-slice asset inventory.

## Non-Goals

- No final production asset batch is implemented in this ticket.
- No all-50-floor art inventory.
- No gameplay, balance, save, or simulation changes merely to make art easier.

## Invariants

Presentation resources remain outside authoritative simulation/save state.
Final art does not change deterministic gameplay meaning or reveal hidden
information.

## Save Impact

None expected.

## Tests / Observation

- Complete and record the Art Production Ready gate evidence.
- Run any registry/resource validation required by the implemented pipeline.
- Re-check representative Godot placeholder flows if asset-contract changes are
  made while closing readiness gaps.
- Run the canonical full repository verification for code/tooling changes.

## Acceptance Criteria

`docs/gates/ART-PRODUCTION-READY.md` records a passing result with explicit
first-slice art-direction, pipeline, registry, inventory, UX-stability, and
binary-policy evidence.

If required visual direction or repository policy cannot be resolved from
existing authoritative sources, stop as `blocked` with the smallest explicit
human/product decision needed. Do not mark this ticket implemented and do not
create production-art batches.

## Definition of Done

After the gate passes, update the umbrella ExecPlan, move it to completed if no
other playable-client work remains, and add the first focused production-art
batch tickets to the canonical ledger from the validated asset inventory.
