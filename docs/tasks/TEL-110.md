# TEL-110 — Author the floors 1–5 dungeon biome and band data

## Status

Implemented and verified.

## Outcome

`DungeonBandDefinition` is the engine-independent v1 biome configuration unit.
The content pack loads one Upper Ruins band covering inclusive floors 1–5
through `ContentPack.Bands`; no separate biome schema is introduced.

## Scope

- Added the validated band schema, stable read-only catalog, ordinal JSON
  loading, floor lookup, and overlap/range validation.
- Added `content/bands/upper-ruins.json` with structural generation and
  presentation configuration plus stable deferred encounter and loot IDs.
- Feature weights and the ecology definitions owned by TEL-112, TEL-114, and
  TEL-116 remain deferred; no resolver or gameplay rule is duplicated here.

## Non-goals

No floors outside 1–5, second biome, encounter/loot/feature/monster roster,
layout or movement behavior, renderer behavior, tuning policy, or save-schema
change was added.

## Invariants and version impact

Band definitions remain content/configuration and do not mutate simulation
state, emit events, consume RNG, reveal knowledge, or add renderer dependencies.
Ranges are validated before catalog publication and repeated loads preserve
stable catalog order. Save DTOs, migrations, save version, and content-version
fields are unchanged.
