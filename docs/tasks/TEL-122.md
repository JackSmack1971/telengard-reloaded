# TEL-122 — Implement Godot client session and scene flow

## Design Intent

Provide the production client navigation/state shell for startup, character
creation, inn, dungeon, menus, death, and return flows while deriving gameplay
state from the authoritative simulation.

## Specification References

§26; §36–§38; §47–§48; §51–§52.

## Dependencies

TEL-120, TEL-121.

## Required Blueprint Context

- `docs/presentation/GODOT_CLIENT_BLUEPRINT.md`
- `docs/presentation/UX_INTERACTION_BLUEPRINT.md`
- `docs/exec-plans/active/GODOT-PLAYABLE-VERTICAL-SLICE.md`

## Requirements

- Add state-driven presentation flow for startup/new/load, character creation,
  inn/preparation, dungeon, pause/menu, death/Legacy replacement, and
  return-to-inn outcomes.
- Use renderer/application state to select scenes/overlays; do not create a
  second authoritative gameplay state machine.
- Define deterministic focus/cancel behavior for required modals.
- Prevent gameplay input leaking through presentation-only modal contexts.
- Keep required first-slice actions reachable without developer/debug tooling.

## Non-Goals

- No final UI styling or production art.
- No full inventory/spell/journal implementation beyond shell/navigation needs.
- No new gameplay policies.

## Invariants

Opening/closing presentation-only UI does not mutate GameState. Gameplay
transitions occur only through existing command/application boundaries.

## Save Impact

None expected. Scene/navigation state is presentation-only unless an existing
authoritative state already records the corresponding domain fact.

## Tests / Observation

- Focused state-flow/navigation tests where practical.
- Verify presentation-only navigation leaves authoritative save/state unchanged.
- Exercise required transitions in Godot with placeholders.
- Canonical full verification for code changes.

## Acceptance Criteria

A hosted session can navigate the required first-slice client states using
placeholder UI and derive those states from authoritative simulation/application
truth without scene transitions becoming gameplay authority.
