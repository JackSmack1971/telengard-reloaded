# TEL-127 — Verify playable Godot vertical slice

## Status

Not started. **Post-MVP acceptance.** TEL-132 / the Five-Floor MVP Demo gate is
a prerequisite and must pass first.

## Design Intent

Prove that real first-slice content and the production-shaped Godot client form
one complete player-usable loop through the authoritative simulation, using
placeholder/graybox presentation where final assets are not yet authorized.

This is deliberately broader than the Five-Floor MVP. The MVP proves that the
central dungeon experience is demonstrably playable; TEL-127 later proves the
full first-slice client breadth.

## Requirements

- Confirm TEL-132 has already recorded a passing Five-Floor MVP result.
- Execute every acceptance item in `docs/gates/GODOT-PLAYABLE-SLICE.md` using
  real authored content and a fixed seed.
- Exercise keyboard and controller paths required by the gate.
- Verify authoritative equivalence across save/resume.
- Confirm no required gameplay step depends on developer/debug commands.
- Confirm Godot consumes renderer-safe presentation state/events and owns no
  authoritative gameplay results.
- Record presentation-only defects separately from gameplay/architecture gate
  failures.
- Record exact Godot/runtime version and manual acceptance evidence.

## Non-Goals

- No weakening or expanding the preceding MVP gate; TEL-132 owns that checkpoint.
- No final production-art batch.
- No Art Production Ready decision; TEL-128 owns that separate gate.
- No broad 50-floor content expansion.
- No weakening acceptance criteria to accommodate unavailable Godot tooling.

## Invariants

The acceptance run uses the same renderer-independent simulation/save/content
contracts as headless verification. Visual acceptance must not create separate
gameplay truth.

## Acceptance Criteria

After the Five-Floor MVP has passed, `docs/gates/GODOT-PLAYABLE-SLICE.md`
records passing evidence for the full real first-slice client. Remaining
final-art/style/pipeline readiness is explicitly left to TEL-128.

## Definition of Done

Update the active umbrella ExecPlan with the playable-gate result. Keep the plan
active for TEL-128; do not author production-art batches until Art Production
Ready separately passes.
